# Rule-Based Chatbot 🤖

A simple command-line chatbot built in Python that uses dictionary-based pattern matching to respond to predefined user queries. Built as part of my AI Internship at **Decode Elab**.

---

## 📖 About
This project is part of my AI Internship at Decode Elab. The goal of this project is to learn how a rule-based chatbot works by building it from scratch using Python — using dictionary-based pattern matching rather than machine learning or NLP.

As the project progresses, this repository will be updated with new features, documentation, and improvements.

---

## ✨ Features
- Case-insensitive and whitespace-tolerant input handling
- Graceful handling of empty input
- Simple exit commands: `quit` or `bye`
- Easily extendable response dictionary
- Fallback response for unrecognized queries

---

## 🛠️ Tech Stack
- Python 3.13
- No external libraries required

---

## ⚙️ Installation
```bash
git clone https://github.com/mismailbutt/rule-based-chatbot
cd rule-based-chatbot
python main.py
```

---

## 💬 Usage
Run the script and start chatting:
```
hi
Hi! Hope you are doing well.

how are you
I am fine. What about you?
```
Type `quit` or `bye` anytime to exit the chat.

---

## ⚠️ Limitations
This is a rule-based chatbot — it matches exact predefined phrases only. It does not use NLP, machine learning, or fuzzy matching, so unlisted queries will return a default fallback response.
